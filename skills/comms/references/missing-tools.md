# When a command-line tool is missing

1. Name the missing tool and the operation it blocks: "gh is missing, so I can't read the PR."
2. Give the install command for the user's platform and package manager in a code block.
   Verify the command against official instructions; ask if the environment is unclear.
3. Continue work that does not need the tool, and say which operation is waiting.
4. Ask before installing software or changing system configuration.
   Explain any additional trust or permission the installation requires.
5. Give the user interactive login steps when needed; keep credentials out of the conversation.
6. When the tool is ready, verify availability and resume with prior decisions intact.
